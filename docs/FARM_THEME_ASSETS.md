# 农场 UI 素材（2026-10-08）

- farm-scene.svg：本站原创 SVG，等角菜畦、蔬菜、木屋、温室、栅栏与浇水壶。沿用本站原创图形 MIT 许可，不使用腾讯 QQ 农场游戏资产。纯 UI 装饰，不是新闻照片，不声明可玩。
- ZCOOL KuaiLe 标题字体：Google Fonts 官方分发，版本 v22；仅标题所需中文子集 11,336 字节，保留 static/fonts/farm-theme/OFL.txt（SIL OFL 1.1）。正文不使用该字体。来源：https://github.com/googlefonts/zcool-kuaile 。
- 木质边缘、木纹、铆钉与按钮：本站 CSS。栏目入口只跳转真实现有正文锚点；移动端可横滑，避免挤占阅读。
- 新闻图片使用 data/editorial_media.json 中 original-source-photo；来源与图级许可在图注展示。历史图库资产未引用部分保留文件用于可逆回滚，但不进入正文。
