# 首期编辑与自动生成边界
首期2026-10-04为真实claude-sonnet-5模型草稿，经主编逐条核对原始来源后修订。修订包括研究阶段、粮食政策范围、没有依据的深度/体积/周期、地域与品种条件。不是将旧AI日报标题替换为农业，也不是模型失败时静默发布假稿。原始模型回执和完整来源保存在私有生成器evidence/，公开修改摘要为FIRST_EDITION_REVIEW.json。

后续生成器改为每来源选择一段可核对事实，模型只译写标题/摘要，以来源id为对象键保证一来源一条；适用条件和行动边界由预先审核的编辑规则填充。实操与误区采用核实过的技术题库，按当期日期轮换，另列必要的支持来源，不能拿支持来源重复凑日报条数。数字、单位、用量、周期与高风险表述未经编辑复核时停发。模型摘要校验仍不能证明所有语义绝对正确，来源变化或风险内容需维护者复核。

原项目测试依赖旧业务/Worker配置，不向新项目迁入；解析/日期/去重/证据/写入隔离有新测试，游戏有状态/奖励/时钟/坏存档/存储失败测试。浏览器验收在隔离Chromium151上进行，桌面1280与手机390，线上地址https://farm.aibioo.cn；不会读取用户日常浏览器密码或会话。
